# 社区与资源市场分类

管理员在 `/admin?tab=communityCategories` 和 `/admin?tab=marketplaceCategories` 中新增、改名、排序、删除分类，也可以搜索现有内容并重新分类。排序值越小越靠前，相同值按标识符排序。标识符创建后保持稳定，中文名和英文名可以修改。

分类表复用 `task_types`，使用 `scope` 隔离任务、社区、市场三个目录。标识符全表唯一；`posts.category`、`products.category` 是业务分类，独立于作品媒体格式和商品 `product_type`。数据库触发器与外键共同阻止跨目录引用及悬空引用。

删除非空分类必须选择同目录的接收分类；事务内移动所有引用再物理删除分类，不删除帖子、商品或资产。省略发布分类的旧客户端会使用当前目录排序第一的分类；目录为空时无法发布，需管理员先新增分类。已存草稿省略分类更新时保留原分类。

公开目录接口为 `GET /api/v1/task-types?scope=community|marketplace`。列表接口以 `category` 参数在数据库筛选，社区游标分页保持分类条件。发布帖子和作品抽屉使用相同目录，列表与详情使用目录中的本地化名称。

两个页面在视口宽度大于 1320px 且目录非空时显示分类侧栏并隐藏工具栏分类下拉框；其余宽度显示下拉框。分类选择写入 URL，刷新与返回可恢复筛选。

验证覆盖真实 PostgreSQL 中的分类隔离、改名排序、引用转移、默认分类删除、草稿分类保留、社区分页、商品格式与价格不变，以及 HTTP 权限。Playwright 覆盖两目录管理、桌面/手机显示互斥和商品重分类后转移删除。
