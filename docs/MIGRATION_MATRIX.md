# HCAI CHAT migration matrix

This matrix maps the current `/Users/helong/Work/newchat` worktree to the Go and Vue rebuild. The source worktree is read-only and is evaluated from its current files, not only commit `ba8b185d`.

Status values:

- `implemented`: target code and verification evidence exist.
- `in_progress`: target boundary exists but the full user workflow or parity evidence is incomplete.
- `externally_blocked`: the safe boundary exists, but credentials, legal approval, or an external system are required.
- `planned`: audited and required, but target code does not exist yet.

Capability rows evaluate the complete local product required by the goal. Production-only credentials, regulated services, infrastructure, and legal or operational approvals are tracked separately under **External acceptance boundaries**; they do not leave an otherwise verified local workflow ambiguously `in_progress`.

## Migration rules

1. A source capability may be consolidated into a smaller target model only when its state invariants and audit evidence remain explicit.
2. Hiding a button is not authorization. Every target mutation must enforce ownership or permission in Go.
3. `implemented` requires code plus tests or browser evidence. Schema or placeholder UI alone is `in_progress`.
4. Demo media, local providers, and test checkout must be labeled in API metadata and visible UI.
5. This matrix is updated at each completed vertical checkpoint.
