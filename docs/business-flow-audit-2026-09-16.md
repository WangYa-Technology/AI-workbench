## 优先问题

### P1：浏览器业务回归与当前界面/合约脱节（本地回归已修复）

全量套件配置 166 项，本轮运行到中止时：8 通过、19 失败、1 中断、138 未运行。因前段反复出现旧页面/旧流程断言，本轮停止全量运行并转为定向验证；不把未运行项记为通过，也不把 19 项都断言为产品故障。

已核实的代表性原因：

- `web/e2e/admin-models.spec.ts:10` 查找 “Model routing”，实际页面为 “Default model”；后续字段和确认流程也已改变，不能仅改标题就声称该流程恢复覆盖。
- `web/e2e/community-governance.spec.ts` 只按标题查找 heading，帖子标题和关联作品标题相同时命中 h1/h2 两个元素；应明确选主标题。更多菜单迁移后旧操作入口也需更新。
- `web/e2e/product-purchase.spec.ts` 仍以即时 Local Test 购买/退款为前提；当前公开结账 API 使用 Provider checkout。该文件在本轮中止前尚未执行，其问题来自源码核对。
- 认证、上传和后台目录亦有失败，尚未逐个完成根因分类，不能全部归为文案问题。

建议先按真实用户可访问入口和当前支付边界修复关键路径测试，将过时的 Local Test 场景与 Provider 场景拆开；保留支付关闭时的拒绝用例。测试中应固定每条链路自己的数据，避免上一条发布内容影响下一条的 `first()` 选择。

### P2：密码输入允许范围超过 bcrypt 上限（已修复）

`internal/identity/repository.go` 的 `validateRegistration` 和 `internal/emailactions/service.go:218` 的重置入口允许最多 128 字节，然后调用 bcrypt。bcrypt 对超过 72 字节的输入返回错误，错误没有归类为业务校验错误；重置接口最终进入内部错误分支。前端 AuthPage/EmailActionPage 又以 `maxlength=128` 限制字符数，中文等多字节密码更早触发。

本地运行当前依赖验证：72 个 ASCII 字节成功；73 个 ASCII 字节、25 个“密”（75 字节）均返回 `bcrypt: password length exceeds 72 bytes`。

建议统一前后端的字节/字符策略，在哈希前返回明确校验错误，补 72/73 字节与多字节边界测试；若决定支持更长密码，应采用明确的哈希迁移方案。不得通过截断密码解决。

### P2：取消商品支付返回不存在的路由（已修复）

`internal/transport/httpapi/marketplace.go:69` 原来生成 `/market/products/:id?payment=cancelled`，但前端产品详情路由是 `/market/assets/:id`。旧地址命中兜底重定向，用户会离开原商品。

已改为正确详情地址，并在 `TestProductCheckoutAndRefundHTTPContract` 中验证传给模拟支付 Provider 的完整 `cancel_url`。该集成测试通过；这是模拟 Provider 的 HTTP 合约证据，不是真实支付平台验收。

### P2：全局样式和后台键盘访问存在可复现问题（已修复）

- 公告正文浅色对比度 4.46:1，小于自动检查要求的 4.5:1：改用共享 `--text-secondary`。
- 资产类型标签暗色对比度 2.48:1：暗色标签文字改用共享语义色，保留类型背景。
- 设置页选中导航说明暗色对比度 4.37:1：在共享分类面板中统一选中链接说明文字颜色。
- 后台诊断等无操作控件的长内容无法聚焦内部滚动区：为 `admin-page-scroll` 提供键盘焦点和与当前栏目一致的区域名称。

### 第三轮发现的实际缺陷

- 后台排名表单引用 UiRadio 但没有导入，Vue 将其当作未知元素。补齐共享组件导入，国际化回归同时检查运行时警告。
- 创作台切换媒体模式没有同步 URL，草稿仍按旧 props.mode 保存；现在同步路由、响应路由模式变化，并按实际模式保存草稿。
- 资产使用记录已经链接到创作会话，但其中 generationId 没有被处理。现在在对应结果加载后打开其详情，不因后台轮询反复打开已关闭的弹层。
- 任务关联生成结果缺少“提交交付”入口；现在从结果自身 sourceTaskId 和 outputAssetId 生成任务交付链接，预选生成资产。
- 任务 API 固定使用 Provider 结算路径。对 fixture 准备但没有已付款记录的任务，验收返回 409 是正确资金保护；浏览器测试验证交付、返修后，拒绝无资金验收且不生成结算，不将该场景称作已完成结算。

测试修正还包括：通过站内关闭登录页验证内存草稿（不把完整刷新当成站内导航）；移动横幅使用内容自适应和容纳约束（共享样式明确移除了 320px 最小高度）；确定选择带公开提示词的种子作品，避免前序测试的新私有作品污染复制测试。
