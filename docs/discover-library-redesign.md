# 灵感库改版

> 本文为改版背景记录。2026-09-18 的实际链路、权限边界、修复及验收记录见[灵感库全链路说明](inspiration-library-flows.md)。

页面与任务广场、社区和资源市场采用同一结构：PageHero 顶部概览、54px 筛选栏、数量及说明、列表／网格展示。删除旧版单件作品大幅推荐、重复导航卡片和独立“最新作品”区。主区中的每件作品都保留详情、创作者主页；图片作品保留原有二次创作链接。

媒体类型由作品资产格式决定，不与社区、市场的管理员业务分类混用。宽屏使用分类侧栏，1320px 及以下用下拉框；手机筛选栏换行。图片、视频、音频和文本使用已有媒体组件。作品卡展示标题、摘要、作者、模型、发布时间及提示词可见性；不把提示词公开误称为商业授权。

筛选条件 q、kind、promptVisibility 写入 URL，刷新及浏览器返回可以恢复。GET /works 在数据库先筛选再分页，默认最新发布，每页 12 件；返回的游标包含时间与作品 ID，避免相同发布时间漏项，兼容旧时间游标。加载更多失败时保留现有结果并提供重试。新筛选请求使旧请求结果失效。

顶部统计基于已加载作品，不声称为全站总量。空库、无筛选结果、初始加载失败及下一页失败各有独立反馈。测试覆盖真实数据库筛选及同时间分页，浏览器覆盖 URL 恢复、双布局、移动端、空状态、重试、加载更多和原有作品跳转。

二次创作入口补齐创作页的来源读取：只预填服务端允许返回的公开提示词，显示可移除的来源作品，并在生成请求中保留 sourceWorkId。生成详情提供发布入口，进入现有资产发布弹窗，端到端测试覆盖生成、资产保存和发布到社区。
